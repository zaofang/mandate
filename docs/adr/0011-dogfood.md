## Context
The process is only credible once it has run a real project.

## Decision
The Mandate repository follows its own spec from milestone 001. Until the template exists, `docs/spec/agents.md` stands in for `.mandate/agents.md`.

## Consequences
Spec gaps surface in Mandate's own close-outs first. Mandate uses the tooling profile with `docs/spec/` gated.

## Alternatives
Build ad hoc and adopt later (the process is first tested on a project that matters).
