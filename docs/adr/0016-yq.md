---
id: 0016
title: The CLI may use yq for YAML
status: accepted
date: 2026-11-12
---
## Context
`mandate check` must verify that every required check in the ruleset JSON names a job that runs on every pull request. Job names and triggers live in workflow YAML, which `jq` cannot read and `grep` cannot read reliably.

## Decision
The CLI is bash 5 over `git`, `gh`, `jq` and `yq` (mikefarah, v4). `yq` is used only where YAML must be read. This extends ADR-0010.

## Consequences
One more tool to install locally; GitHub-hosted runners ship it. YAML front matter in Mandate's own documents may also be read with `yq`.

## Alternatives
Naming convention checked by `grep` (brittle on valid YAML variations). Dropping the check (a wrong context name blocks every merge silently).
