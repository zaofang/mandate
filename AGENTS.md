# AGENTS.md

Project-specific instructions for Mandate. The framework contract is loaded separately through `CLAUDE.md`.

- Until the template milestone ships `.mandate/agents.md`, `docs/spec/agents.md` is the contract.
- `docs/spec/` is normative and gated. Spec changes need an ADR when they change a decision recorded in one.
- Keep the spec terse: rules and formats, no rationale. Rationale belongs in ADRs.
- Shell scripts, once they exist, must pass `shellcheck`.
